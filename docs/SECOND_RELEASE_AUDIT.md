## 配置与回滚注意事项

- Worker 数量由 APP_WORKER_COUNT 控制（默认 1），也可用 `docker compose --scale worker=2` 覆盖。
- 现有公开状态保持 completed，不能直接改成 succeeded 破坏调用方；需要明确版本和兼容映射。
- 恢复脚本只写新目录，不自动覆盖现有 data。真正目录切换需要停机、验证路径和外部密钥，并保留旧目录。
- 本次没有删除旧数据库字段；尚未提供逐版本自动降级迁移，不能把恢复快照说成任意版本数据库可逆迁移。
