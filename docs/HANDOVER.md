# AgentNexus（智枢）开发交接文档

更新时间：2026-08-26（Asia/Shanghai）

本文是开发和维护交接记录，不是面向普通用户的产品宣传页。它说明当前代码如何组成、如何启动、哪些能力已经实现、哪些能力只适合本机开发，以及接手后应先验证什么。

## 1. 当前状态

当前工作区包含一套 FastAPI + SQLite 的单机智能体平台。前端位于 `web/`，后端入口是 `app/main.py`，标准 Python 文件名没有改成其他名称。项目目录名是 `AgentNexus`，产品中文名为“智枢”。

当前代码改动尚未提交或推送到 Git。`git status` 中的修改和未跟踪文件均属于本地工作区版本；不要用 `git reset` 或 `git checkout` 覆盖它们。

最近一次真实验收确认：健康接口可用，默认项目和默认助手均使用已配置且测试通过的 `gpt-5.5`；普通任务可以恢复对话上下文、动态生成计划、显示 Skill/MCP/模型子节点、流式更新事件、生成 Markdown 文件，并在最终验收通过后提供下载。任务概览、运行控制和执行过程在空闲/成功完成后默认收起；运行中、等待补充/审批或失败时自动展开，失败原因会在对话区和追踪区域同时显示。Markdown 发布格式别名问题已修复，避免数据库 `markdown` 与验收层 `md` 不一致导致误报失败。本轮浏览器实测还确认在线任务先出现“正在处理/实时”，完成后回答和状态正确，控制台无 error/warn。

## 2. 运行结构

```text
浏览器
  -> web/index.html + web/app.js + web/styles.css
  -> FastAPI /api/* 与任务 SSE
  -> app/main.py
     -> AgentRuntime：上下文、目标、计划、Skill、工具、输出
     -> ModelGateway：离线模型或 OpenAI-compatible Chat Completions
     -> SkillRegistry：Skill 包和版本
     -> MCPGateway：内置、stdio、远程 HTTP、普通 HTTP 工具
     -> TaskState / Verification：节点、检查点、候选结果和最终验收
     -> SQLite：配置、任务、事件、记忆、知识库和产物索引
```

运行数据默认位于：

```text
data/platform.db
data/.secret_key
data/uploads/
data/artifacts/
```

这些内容可能包含 API 密钥材料、用户文件、任务上下文和生成文件，不应提交到 Git 或通过静态文件暴露。

健康检查：

```bash

```

应该得到包含 `"ok": true`、`"name": "AgentNexus"` 和 `"display_name": "智枢"` 的 JSON。若端口被旧进程占用，先查 `lsof -nP -iTCP:8000 -sTCP:LISTEN`，确认是本项目进程后再停止旧进程。

不要双击 `web/index.html` 或使用 `file://` 打开；这样没有后端连接，模型保存、任务、上传和下载都会失败。

## 4. 模型配置

平台内置“离线确定性模型”，用于页面和流程冒烟，不是通用大模型。真实模型配置支持 OpenAI Chat Completions 兼容协议：

- 环境变量模式：页面只保存变量名，例如 `OPENAI_API_KEY`；密钥必须存在于启动后端的进程环境。
- 直接 API Key：后端使用本机 Fernet 密钥加密后保存，API 和页面不回显明文。
- `openai` 与 `openai_compatible`：都要求 Base URL 能处理 `/chat/completions`。

在线模型还必须同时满足：

```text
APP_ALLOW_OUTBOUND_NETWORK=true
APP_MODEL_HOST_ALLOWLIST=供应商主机名
```

保存模型后，应在“模型设置”中看到模型卡片，先点“测试连接”，再回工作台的模型选择器确认可选。修改 `.env.local` 或环境变量后必须重启服务。

## 5. 已实现功能清单

### 对话与任务运行

- 普通模式：一个 Agent 根据当前上下文匹配已启用 Skill 和工具。
- 专家模式：使用已创建且启用的专家团，成员独立并行，主管汇总并按验收条件检查。
- 上下文还原、长期记忆、会话摘要和当前目标优先级。
- 动态上层计划节点，以及 Skill、模型、MCP Server、具体工具和知识库的下层节点。
- 任务事件 SSE、有限断线重连、运行中追加指令、取消、重试、检查点和服务重启恢复。
- 工具调用前的 GoalSpec、Schema、权限、Policy 和参数复验。
- 输出前的规则验收、产物存在性/可读性/Hash 检查和语义复核；未通过不发布为完成。
- 缺少必要参数时返回简短的补充问题，不向用户展示模型隐藏思考内容。

### Skill

支持在“技能中心”创建、编辑、启停、导出和查看文件，也支持导入 `SKILL.md`、ZIP 或受控 HTTPS 直链。对话中遇到能力缺口时，可以推荐少量内置 Skill，用户确认后安装并在同一任务继续；拒绝则不安装。Skill 包内脚本不会自动执行。

### MCP 和工具

支持内置工具、本地 stdio MCP、远程 Streamable HTTP MCP 和普通 HTTP 工具；支持 JSON 导入、手工创建、工具发现、服务启停和 Agent 绑定。默认关闭外部网络、stdio、远程 MCP、HTTP 工具和远程安装，并通过主机/命令白名单限制目标。

页面直调仅允许明确只读工具；写入或不明确副作用的工具必须从正式任务运行链调用。

### 文件和产物

上传默认可用。当前可提取 TXT/MD/CSV/JSON/YAML/代码、DOCX、XLSX、PPTX 和可搜索 PDF 的有限正文；不包含 OCR、图片理解或音视频转写。

已实现基础产物链路：Markdown、HTML、DOCX、PDF、XLSX、CSV，以及平台内置 Python `python-pptx` 生成器提供的 PPTX。若部署环境已有受支持的 Artifact Tool，也可以按配置向导接入外部生成器。文件有预览、下载、版本、MIME、大小和 SHA-256 验证；长内容 PPTX 会自动分页，不会因为旧的 8 页示例限制而静默失败。

### 知识库

当前已经实现基础知识库，不应再按“暂缓”描述：

- 创建、编辑、启用/停用和删除知识库。
- `private`、`workspace`、`organization` 三种逻辑可见范围。
- 从已上传文件建立文本索引，保存文档和分片。
- 关键词检索，任务执行时注入可见且启用的命中片段，并在过程里展示来源文档和片段编号。

它仍不是完整企业级 RAG：没有向量索引、混合检索、同步连接器、页级引用、可信登录主体和强制租户隔离。

### 自动化、工作区和治理

支持手动、interval、Cron、once、签名 Webhook、幂等键、重试/退避、非重入、站内通知和任务下钻。工作区目前是逻辑作用域；Policy、权限快照、工具效果日志和任务审计已具备基础实现。

## 6. 实际使用验收顺序

按以下顺序测试，出错时先看右侧“执行过程”和“调用明细”，不要只看最终回答：

1. 打开 `/api/health`，确认后端实例正确。
2. 打开“自检”，确认模型、上传、Skill/MCP、产物和知识库能力状态。
3. 在“模型设置”保存一个模型，确认模型卡片出现，再测试连接。
4. 工作台选择模型和普通模式，发送“请回复：模型连接测试通过”，确认回答出现。
5. 发送“记住：本次验收代号是星云-218”，再在下一条消息引用该代号，确认上下文生效。
6. 上传一个小型 TXT/MD 文件，要求总结并生成 Markdown 或 Word，确认执行节点、文件和下载链接。
7. 创建知识库，上传刚才的文件，等待索引完成，使用知识库页检索关键词，再发送引用该资料的任务，确认出现知识引用节点。
8. 在技能中心创建或导入 Skill，确认列表中可见且启用；需要外部安装时先检查出站总开关和远程安装白名单。
9. 在工具接入创建内置或本地 MCP，发现工具并绑定 Agent；没有明确配置权限时不要直接调用写工具。
10. 生成 PPTX 前先查看能力页的 `pptx_configured`；当前本机可直接使用内置 Python 生成器，也可以在对话中发送“直接给我配置好 PPT 工具”。若能力确实未配置，必须在对话中给出明确原因和配置入口，而不是生成损坏文件。

## 8. 尚未完成或不能对外承诺

- 可信登录、完整 RBAC、真实多租户行级隔离和资源所有权。
- 每任务容器/微虚拟机沙箱、CPU/内存/网络配额和用户本地 Runner。
- Skill/MCP 市场的发布者签名、版本锁、依赖预览、升级和回滚。
- OAuth 连接器、跨渠道消息入口、统一 Plugin/解决方案包。
- KMS/Vault、租户级密钥轮换与撤销。
- 完整文件树、Diff、批量下载、分享撤销和保留策略。
- 知识库向量/混合检索、同步连接器、页级引用和检索评测。
- Docker 镜像的真实构建和容器启动冒烟尚未在当前机器验证；本机没有 Docker CLI。

当前适合本机开发或受控内网，不应未经认证、授权和执行隔离加固直接暴露到公网。
